Flexbox Layout

Flexbox is a one-dimensional layout system that makes it easier to arrange and align elements in rows or columns.

Feature 01

Flexible Layout

Flexbox helps arrange elements in a row or column and allows them to adapt to the available space.

Feature 02

Easy Alignment

Properties such as justify-content and align-items make horizontal and vertical alignment easier.

Feature 03

Responsive

Flexbox can change from a row layout to a column layout when the screen becomes smaller.

CSS Grid Layout

CSS Grid is a two-dimensional layout system that allows content to be organized using rows and columns.

Columns

CSS Grid allows us to create multiple columns and organize content in a structured layout.

Rows

Grid can organize content using both rows and columns, making complex layouts easier to create.

Grid Gap

The gap property creates consistent space between rows and columns.

How the Layout Works

This webpage uses both Flexbox and CSS Grid to organize the content. Flexbox is mainly used for one-dimensional layouts, while CSS Grid is useful for two-dimensional layouts.

Flexbox Settings

  • display: flex; activates Flexbox.
  • justify-content: controls horizontal alignment.
  • align-items: controls vertical alignment.
  • flex-direction: controls whether items are arranged in a row or column.
  • gap: creates space between Flexbox items.

CSS Grid Settings

  • display: grid; activates CSS Grid.
  • grid-template-columns: defines the number of columns.
  • repeat(3, 1fr): creates three equal columns.
  • gap: creates space between Grid items.

Responsive Design

The webpage uses CSS media queries to respond to different screen sizes. On tablets the Grid changes to two columns. On mobile phones it changes to one column. The navigation menu also changes from horizontal to vertical.

Website Features

  • Navigation Menu: Use the menu to move between different sections of the webpage.
  • Flexbox: Used to arrange content in a flexible row or column.
  • CSS Grid: Used to organize content into rows and columns.
  • Images: Images make the webpage more visual and engaging.
